# Security Policy

## Supported Versions

This project is currently maintained for the latest `main` branch only.

| Version | Supported |
| ------- | --------- |
| main    | ✅ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, critical bug, or sensitive issue, please report it privately through GitHub's private vulnerability reporting feature if enabled.

If private reporting is unavailable, please open an Issue labeled `security` or contact the repository owner directly.

For general bugs, feature requests, or simulation errors, please use the public Issues page.

### Response Expectations

- Initial acknowledgment: within a reasonable timeframe
- Triage: issue will be reviewed and classified
- Resolution: fixes will be prioritized based on severity and project scope

Thank you for helping improve the reliability and safety of this project.
