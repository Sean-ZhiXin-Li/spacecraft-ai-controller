# Phase38D Principal Patterns

Scope: principal evidence patterns found by mining existing CSV fields. No controller experiments were rerun.

## Pattern 1 - Crossing Is A Discrete Boundary

Crossing-state fields only exist after target-radius crossing. This reinforces the project claim that crossing is a discrete transition, not a smooth proxy metric.

## Pattern 2 - Radius Regime Is The Clearest Descriptive Class Separator

The reduced benchmark shows a strong class association with `r0_over_target`. This is useful for analysis conditioning but cannot be used as a controller variable by itself.

## Pattern 3 - Timing Signature Exists But Is Not Causal Yet

`closest_approach_step` separates near-crossing and over-conservative-transfer signatures. This strengthens a timing-analysis hypothesis but does not approve coast duration or radial timing implementation.

## Pattern 4 - Proxy Metrics Move Without Crossing

`best_crossing_potential` and `min_abs_radius_error_ratio` are informative, but Phase36C and Phase37B show that improvement in these fields does not guarantee target-radius crossing.

## Pattern 5 - Tested Local Control Variables Are Weak Or Contradicted

Radial timing, radial magnitude, and weak tangential shaping have direct negative evidence. They should not be expanded into Phase39 without a new registered hypothesis and stronger controls.

## Pattern 6 - Existing Crossing Cases Must Be Regression Guards

The known crossing-producing cases are the protected asset. Any future implementation that damages them should be rejected even if it improves a selected non-crossing case.
