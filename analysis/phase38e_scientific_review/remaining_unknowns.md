# Phase38E Remaining Unknowns

## Unknowns About Failure Mechanism

- Whether the radius-regime separation generalizes beyond the reduced 24-case benchmark.
- Whether closest-approach timing is causal or only descriptive.
- Whether any threshold in `best_crossing_potential` predicts actual target-radius crossing.
- Whether over-conservative-transfer cases fail because of timing, angular momentum, tangential state, or another unlogged factor.

## Unknowns About Candidate Variables

- Coast duration is not isolated in existing CSV evidence.
- Angular momentum correction is not isolated in existing CSV evidence.
- Tangential shaping cannot yet be separated from regression damage.
- Radial timing cannot yet be separated from the negative Phase37A result.

## Unknowns About Generality

- Whether Phase36C labels remain stable outside the reduced benchmark.
- Whether selected Phase37B cases represent a meaningful class or only a narrow subset.
- Whether future variables can create new crossings without damaging the known crossing-producing set.

## Unknowns About Measurement

- Whether current recorded fields are sufficient to identify a causal upstream variable.
- Whether additional logging would be needed before a controller implementation can be interpreted.
- Whether proxy metrics can be converted into registered predictions without becoming success criteria.
